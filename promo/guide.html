01Allumer et choisir son système

Ta console est en AutoRCM : elle ne démarre jamais seule. Il faut lui envoyer Hekate depuis le PC.

  1. Branche la Switch éteinte au ROG Ally avec un câble USB-C.
  2. Ouvre TegraRcmGUI, choisis le payload hekate_ctcaer_6.5.5.bin (sur le Bureau), puis Inject payload.
  3. Le menu Hekate s'affiche. Choisis :
    • HomeNX : la console de tous les jours (emuMMC, Atmosphère, ton menu HOME) ;
    • Linux (Kubuntu) : le PC Linux de poche (chapitre 09) ;
    • Atmosphère officiel : le secours, avec le menu Nintendo d'origine.

« Redémarrer » depuis la console renvoie directement au menu Hekate : pas besoin de réinjecter.

À retenir : ne laisse jamais la batterie se vider. Avec l'AutoRCM, une console vide oblige à la réinjecter depuis le PC. HomeNX+ prévient à 15 % puis à 8 %. Préfère la veille à « Éteindre ».

02Le menu HOME de tous les jours

Ton menu HOME est HomeNX en apparence Cartes (CardsNX) : une rangée de jaquettes, des pages et une barre en haut.

  • ZL / ZR : changer de page (Jeux, Homebrew, Nintendo, Médias, tes pages perso).
  • A : lancer. + : options du jeu (déplacer, renommer, masquer, fiche HomeNX+). X : fermer le jeu ouvert.
  • L : Discord. R : réglages rapides. − : notifications.
  • Les trois points en haut à gauche : pages, utilisateurs, musique, réglages, alimentation.
  • HOME pendant le menu : ferme les fenêtres ouvertes, puis reprend le jeu en pause.

03HomeNX+ : le menu amélioré

HomeNX+ est ta version de HomeNX, avec tous les ajouts. Pour l'instant, il se lance comme une appli : R enfoncé en lançant un jeu, puis HomeNX+ dans la liste du menu homebrew. Ton vrai menu HOME ne change pas tant que l'installation finale n'est pas faite.

Ce qu'il ajoute

  • Panneau HomeNX+ : trois points > HomeNX+, ou clic du stick gauche. Tout y est rangé.
  • Style : passer de l'apparence Cartes à l'apparence Wii U (et retour par Réglages > HomeNX+). Le menu redémarre en 2 secondes.
  • Recherche : Y, ou tape une lettre sur un clavier USB. Une partie du nom suffit, accents ou pas.
  • Fiche de jeu (+ sur un jeu) : notes, checklist de complétion à cocher, question à Claude sur ce jeu, scène du jeu, copie des saves sur le PC.
  • Scènes : Nuit, Batterie, Perf max. Elles règlent processeur, carte graphique, luminosité et couleurs d'un coup. Une scène choisie pour un jeu s'applique à son lancement et s'arrête au retour au menu.
  • Pages intelligentes : Récents, Plus joués, Jamais lancés. Ranger mes jeux avec Claude : Claude propose des pages par genre, tu acceptes ou non.
  • Batterie et santé : batterie, place sur la carte SD, sys-clk, mode sans échec.
Les réglages de la version de test sont rangés à part (config/homenxplus/) : elle ne peut rien abîmer dans ton menu installé.

04Claude sur la Switch

Claude est l'assistant d'Anthropic. Il marche avec ta clé API, rangée seule dans config/homenxplus/api_key.txt (jamais affichée).

  • Dans HomeNX+ : panneau > Claude. Poser une question, « Que faire ici ? » sur ta dernière capture d'écran, traduire une capture en français.
  • ClaudeNX (appli à part) : A poser une question, ZR joindre la dernière capture, Y nouvelle conversation, X changer de modèle, B arrêter, + quitter.
  • Sous Linux : Claude Code dans le terminal (commande claude).
Coût : chaque question coûte quelques centimes. Le plafond du mois est dans config/homenxplus/config.ini (monthly_cap_eur) ; au-delà, Claude se bloque. Une capture n'est envoyée qu'après ton « Oui ».

Pourquoi Netflix passe par le PC

Ces services n'ont pas d'appli Switch et le navigateur de la console ne gère pas leur protection anti-copie. À préparer une fois sur le PC : Sunshine (ou GeForce Experience) pour Moonlight, Moonlight jumelé avec la Switch, le compagnon PC lancé (chapitre 08) et une connexion à chaque site dans le navigateur.

Image noire dans Moonlight ? Dans le navigateur du PC, désactive l'accélération matérielle (Paramètres > Système).

07Pendant une partie : les overlays

Ouvre le menu des overlays avec L + ↓ + R3 (Ultrahand).

  • HomeNX+ : notes et checklist du jeu en cours (à cocher), scènes rapides, batterie.
  • sys-clk : fréquences. Fizeau : couleurs de l'écran. FPSLocker : images par seconde.
  • Status Monitor : température, batterie, charge. EdiZon : codes de triche.
  • Sysmodules : allumer ou couper un module (ftpd, ChargeCap, key2con…).

08Le compagnon PC

Un petit programme sur le PC, sur le réseau de la maison seulement, protégé par un jeton.

  1. Lance-le : HomeNXPlus\pc_agent\lancer_pc_agent.ps1.
  2. La première fois, carte SD dans le PC, lance outils\installer_sur_sd.ps1 : il relie la Switch au PC.
  • Réveiller le PC à distance (Wake-on-LAN activé dans le BIOS du PC).
  • Copier tes saves et tes captures dans Documents\Switch_Sauvegardes\<date>.
  • Boîte aux lettres : des messages entre la Switch et le PC.
  • Netflix et co : ouverts sur le PC à la demande de la Switch (liste fermée de 4 sites).

09Linux (Kubuntu)

Choisis Linux (Kubuntu) dans Hekate. Tu as un vrai bureau : Chromium, VLC, RetroArch, Dolphin, mGBA, et Claude Code dans le terminal.

  • Outils HomeNX+ dans switchroot/outils/homenxplus/ : rapport de santé, boîte aux lettres, icônes (installer.sh).
  • Pour revenir : redémarre, tu retombes sur Hekate.

10En cas de problème

Le menu HOME ne démarre plus

  1. Carte SD dans le PC : lance secours_menu_home.ps1. Il remet le menu Nintendo d'origine sans rien effacer.
  2. Ou sous Linux : bash switchroot/outils/homenxplus/secours_menu_home.sh.
  3. Ou dans Hekate : Atmosphère officiel.

Autres cas

  • HomeNX+ plante 3 fois de suite : il démarre tout seul en mode sans échec (sans verre, musique ni images en ligne).
  • Plus aucun jeu ne se lance : vérifie que config/sys-patch/config.ini contient patch_emummc=1.
  • HomeNX+ se ferme au démarrage : la raison exacte est notée dans config/homenxplus/cards/start.log.
  • Pour me montrer un souci : remets la SD dans l'Ally ; les rapports sont dans atmosphere/crash_reports.

11Entretien et mises à jour

  • Installer une nouvelle version de HomeNX+ : carte SD dans le PC, outils\installer_sur_sd.ps1. Chaque changement est noté dans VERSIONS.txt à la racine de la carte.
  • Sauvegardes des jeux : JKSV, ou la copie vers le PC (chapitre 08).
  • Firmware : ne le mets jamais à jour sans une version d'Atmosphère qui le gère.
  • En ligne : 90DNS bloque les serveurs Nintendo. Ne les débloque pas, ni l'eShop.
  • Filmer l'écran (menu HOME compris) : Switch Frame Tap envoie l'image au PC ; SwitchFrameTap.exe enregistre en MP4 (R). Coupe-le ensuite dans Ultrahand > Sysmodules.
  • Place : environ 13 Go libres sur 512 Go. HomeNX+ et ses outils tiennent en moins de 60 Mo.
