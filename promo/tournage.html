Switch Frame Tap par câble USB : réglage une seule fois

  1. Démarre la Switch sur HomeNX, attends 30 secondes, puis ouvre l'appli Switch Frame Tap (menu homebrew). Page Beta : active Stream the HOME menu. Redémarre la console.
  2. Switch en mode portable (pas sur le dock), branchée à l'Ally avec le câble USB-C.
  3. Sur le PC, lance Desktop\Emulateurs\SwitchFrameTap\zadig-2.9.exe (accepte la question de Windows).
  4. Menu Options > List All Devices. Dans la liste, choisis Switch Frame Tap (identifiant USB 1209 5F1E). Vérifie bien le nom : pas la souris ni le clavier.
  5. À droite, choisis WinUSB, puis Install Driver (ou Replace Driver). Attends la fin.

À chaque tournage

  1. Switch en mode portable, câble branché, sur HomeNX depuis 30 secondes.
  2. Lance SwitchFrameTap.exe (dans Desktop\Emulateurs\SwitchFrameTap\switch-frame-tap-0.7.23-windows-viewer). L'écran de la Switch apparaît.
  3. R enregistre, R arrête. Les MP4 vont dans Vidéos\Switch Frame Tap.
  4. Pour un jeu en 1080p par câble : active ReverseNX-RT en mode « Docked » dans l'overlay.
  5. Après le tournage, tu peux couper le module : Ultrahand > Sysmodules > Switch Frame Tap.

Sans câble (moins stable) : active Network streaming dans l'appli, même Wi-Fi que le PC, et accepte l'accès réseau privé que Windows demande.
